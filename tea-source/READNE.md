# tea. — Fashion Discovery Engine

## Project Overview
tea. is a fashion discovery website that helps users explore clothing items from different fashion brands in one place. Users can browse clothing, discover different styles, and follow links to the original websites where products are available.

## Main Features
- Browse fashion items from different brands.
- Discover clothing through images and product links.
- Explore different styles and clothing categories.
- Open the original brand website to view or purchase products.

## Technologies
- HTML
- CSS
- JavaScript
- SQL

## Project Goal
The goal of tea. is to make online fashion discovery easier by bringing clothing inspiration and product links together in one website.

## Project Status
The initial website has been developed. Further work will focus on testing, documentation, improvements, and collecting user feedback.
